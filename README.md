# Convert

A modern, minimal unit and currency converter.

**Live:** https://eggx917.github.io/Convert/

## 2.0

- Type a conversion: `5 km to miles`, `32 f`, `5'10"`
- Every pair is a shareable link
- Pinned and frequent pairs, from how you actually convert
- History and Pulse for the last 30 days, on this device
- Keyboard: `/` search, `Enter` copy, `S` swap, `P` pin
- Works offline as an installed app; last ECB rates are cached

## Local

Open `index.html`, or:

```bash
python3 -m http.server 8080
```
