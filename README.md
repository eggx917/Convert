# Convert

A modern, minimal unit and currency converter.

**Live:** https://eggx917.github.io/Convert/

## Features

- 19 categories: length, weight, temperature, volume, area, speed, time, energy, power, pressure, data, angle, frequency, force, fuel, density, cooking, light, and live currency
- Instant two-way conversion, swap, copy, and an “also equals” list
- Light / dark theme
- Currency rates from the ECB via [Frankfurter](https://frankfurter.dev/) (no API key)

## Local

Open `index.html`, or:

```bash
python3 -m http.server 8080
```
