# Convert

A modern, minimal unit and currency converter.

**Live (open this to use the app):** https://raw.githack.com/eggx917/Convert/f4bc0892867f53ae716bf5ca66b110f68e562adc/index.html

`https://eggx917.github.io/Convert/` is not live yet — GitHub Pages has to be turned on once in repo Settings → Pages → Deploy from a branch → `main` / root.

## Features

- 19 categories with line icons, grouped into Everyday / Motion / Science
- Instant two-way conversion, swap, copy, and an “also equals” list
- Light / dark theme
- Currency rates from the ECB via [Frankfurter](https://frankfurter.dev/) (no API key)

## Local

Open `index.html`, or:

```bash
python3 -m http.server 8080
```
